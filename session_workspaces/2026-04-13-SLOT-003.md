## TIER 4: SIEVE + ORACLE PIPELINE

### T4.1 — Sieve + Oracle Specification
**Status: ✅ COMPLETE**

**Deliverable:** `sieve_oracle_spec.md` (design document)

**Two-Stage Architecture:**

| Stage | Component | Input | Output | Purpose |
|-------|-----------|-------|--------|---------|
| **1** | **Quartic Residue Sieve** | Observed spins + state space | Candidate set | Eliminate incompatible states |
| **2** | **Sparse Toric Grover** | Candidates + oracle | True state | Amplify true state signal |

**Stage 1 (Sieve):**
- Extract lane values from observed outputs for each modulus m in [3,5,7,11,13]
- For each candidate state: simulate generator, extract lanes, compare
- Elimination: candidate incompatible iff any lane mismatch
- **Efficiency:** Reduction factor ≈ 1/M where M = 15,015

**Stage 2 (Grover):**
- Simulate Grover's algorithm classically
- Oracle: "does this state produce observed outputs?"
- Amplitude amplification: √N iterations where N = candidate count
- **Complexity:** O(√N) oracle calls

**End-to-End:** O(2^b / M) + O(√(2^b / M)) ≈ **O(2^b / M)** for large M

**Sieve Implementation:**
```python
def sieve_candidates(observed_spins, generator_class, bit_width, basis):
    # Extract observed lanes
    observed_lanes = {m: [s % m for s in observed_spins] for m in basis}
    
    candidates = set()
    for state_candidate in range(1 << bit_width):
        gen = instantiate_generator(generator_class, state_candidate)
        predicted_spins = [gen.next() for _ in range(len(observed_spins))]
        
        # Check all lanes match
        if all(
            [s % m for s in predicted_spins] == observed_lanes[m]
            for m in basis
        ):
            candidates.add(state_candidate)
    
    return candidates
```

**Grover Amplification:**
```python
def grover_search(candidates, generator_class, observed_spins):
    # Classical simulation of Grover's algorithm
    # Maintain amplitude over candidates, apply oracle + diffusion
    # Repeat √N times, sample result
    amplitudes = {c: 1000 for c in candidates}  # Scaled integers
    
    for iteration in range(int(len(candidates)**0.5) + 1):
        # Oracle: mark states that match observations
        for candidate in candidates:
            gen = instantiate_generator(generator_class, candidate)
            is_match = all(gen.next() == obs_s for obs_s in observed_spins)
            if is_match:
                amplitudes[candidate] *= -1
        
        # Diffusion: amplify marked states
        avg = sum(amplitudes.values()) // len(candidates)
        for candidate in candidates:
            amplitudes[candidate] = 2 * avg - amplitudes[candidate]
    
    return max(candidates, key=lambda c: abs(amplitudes[c]))
```

- Theoretical reduction: 1/15,015 ≈ 1 in 15,000

- Coverage: 5,000 / 4,294,967,296 ≈ 0.0001% (missing true state with >99.9% probability)

**Lesson:** Exhaustive sieve is powerful (2^16) but hitting ceiling. Sampling-based estimates fail due to sparse candidate density.

## CRITICAL INSIGHT: THE SIEVE WALL

The sieve + oracle pipeline works by **lane-based elimination**. Candidates must match lane residues across all 5 moduli to survive. For small state spaces, this works perfectly. For large state spaces with sampling, it fails because:

1. **Sampling density:** 5,000 samples from 2^32 = 0.0001% coverage
2. **Candidate sparsity:** True state has ~1/15,015 probability of being in any sample
3. **Estimation breakdown:** Sample count too small to reliably estimate true candidate count

**Solution approaches (for T5+):**
- Larger basis (more moduli → stronger sieve)
- Hierarchical recovery (low bits first, then extend)
- Generator-specific oracles (tailor tests to generator structure)
- Hybrid methods (combine sieve with other constraints)
